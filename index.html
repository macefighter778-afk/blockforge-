🎮 Minecraft Java — Quick Guide

The essentials for new and returning players.

GAME MODES

Survival • Creative • Hardcore

Survival focuses on resources, crafting, exploration and combat. Creative gives unlimited resources and flight. Hardcore is a Java survival variant with one life.

DIMENSIONS

Overworld • Nether • End

Explore the main world, travel through Nether portals and progress toward the End.

CORE SYSTEMS

Mining • Crafting • Enchanting • Redstone

Gather materials, craft gear, improve equipment with enchantments and build machines with redstone.

COMMANDS

Useful Java commands

/gamemode creative
/time set day
/weather clear
/tp <player> <target>

🔧 Java Modding Basics

Simple setup guidance.

1. Pick a loader

Common Java loaders include Fabric, Forge, NeoForge and Quilt. Use the loader required by the mod.

2. Match versions

Check Minecraft version, loader and dependencies on every mod page.

3. Mods folder

On Windows, Fabric documentation uses:

%appdata%\.minecraft\mods

4. Trusted sources

Use established project pages instead of random download mirrors.
